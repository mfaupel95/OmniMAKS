**Zweck:** Sorgt dafür, dass ein Ablauf auch nach Monaten ohne Erinnerung nachvollziehbar und wiederholbar bleibt.

**Wann nutzen:** Wenn ein Ablauf von anderen oder von einem selbst nach längerer Pause genutzt wird. Nicht für einmalige Vorgänge.

**Lauf:** 2026-10-26, trockenlauf, Aufgabe: Dokumentation des Skill-Lern-Ablaufs für einen späteren Leser skizzieren. Keine Datei.

**Ergebnis:** Vier Teile: eine Startnotiz (was ist das, wozu, wo liegt was); ein Regelblatt (Blockgröße fünf, eine Bestätigung je Block, Trockenlauf-Vorgabe, Langform bei Dubletten); eine Schrittfolge für einen Durchlauf; eine Dateibeschreibung für Fortschritt, Index und Vormerkliste. Regeländerungen mit Datum und Begründung festhalten, damit später erkennbar bleibt, warum etwas so ist (zum Beispiel die Ausnahme für die Ratsgruppen, freigegeben am 26.10.2026). Pflege: bei jeder Regeländerung der Startnotiz nachziehen.

**Gelernt:**
- Die Begründung einer Regel fehlt meist. Ohne sie wird eine Ausnahme beim nächsten Lauf als Fehler gelesen.
- Eine Startnotiz mit drei Sätzen Zweck erspart den größten Teil der späteren Rückfragen.

**Grenzen:**
- Keine Dokumentation geschrieben, keine Leser befragt.
- Der Skill verlangt Dokumentationsarchitektur, Verantwortlichkeiten je Abschnitt und Onboarding-Pläne für Teams. Für einen Einzelnutzer bleiben Startnotiz und Regelblatt.
